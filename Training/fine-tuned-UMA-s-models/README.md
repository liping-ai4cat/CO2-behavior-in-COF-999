## Fine-tuned UMA-s models

UMA-s model (`uma-s-1p1`) and is therefore a **derivative work** of it. It is
released under the terms of the
[FAIR Chemistry License](https://huggingface.co/facebook/UMA), and its use is
subject to the
[FAIR Chemistry Acceptable Use Policy](https://huggingface.co/facebook/UMA).

You must have accepted Meta's terms for the base UMA model before using this
checkpoint.

The FAIR Chemistry License text is not reproduced here; it is distributed by
Meta at the link above, behind a gated model page, and should be read there so
you get the version in force. The MIT `LICENSE` at the root of this repository
covers the code only, not this checkpoint.

Because the checkpoint is 1.1 GB it is deposited in the companion data record
rather than in the git repository — see "Where the files are" in the top-level
`README.md`.
